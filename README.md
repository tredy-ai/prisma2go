# prisma2go

Generate Go structs from Prisma DMMF JSON.

## Installation

```bash
go install github.com/tredy-ai/prisma2go/cmd/prisma2go@latest
```

For full enum support (String/SQL/JSON marshaling), also install enumer:

```bash
go install github.com/dmarkham/enumer@latest
```

## Usage

### 1. Extract DMMF from your Prisma schema

```bash
node -e "
  const { getDMMF } = require('@prisma/internals');
  const fs = require('fs');
  getDMMF({ datamodel: fs.readFileSync('prisma/schema.prisma', 'utf-8') })
    .then(d => console.log(JSON.stringify(d.datamodel, null, 2)));
" > dmmf.json
```

### 2. Generate Go structs

```bash
# Basic usage
prisma2go generate -i dmmf.json -o models/models.go -p models

# From stdin
cat dmmf.json | prisma2go generate -p models > models.go

# With config file
prisma2go generate
```

## Config File

Create `prisma2go.yaml` (or `.prisma2go.yaml`):

```yaml
input: dmmf.json
output: models/models.go
package: models

# Struct tags (all default to true)
json_tags: true
db_tags: true
json_omitempty: true

# Type options
uuid_package: "github.com/google/uuid"  # or "" to use string
decimal_package: ""                      # or "github.com/shopspring/decimal"
```

## Type Mapping

| Prisma Type | Go Type |
|-------------|---------|
| `String` | `string` |
| `Int` | `int32` |
| `BigInt` | `int64` |
| `Float` | `float64` |
| `Boolean` | `bool` |
| `DateTime` | `time.Time` |
| `Json` | `json.RawMessage` |
| `Bytes` | `[]byte` |
| `Decimal` | `string` (or shopspring/decimal) |
| `@db.Uuid` | `uuid.UUID` (or string) |
| Nullable X | `*X` |
| Array X | `[]X` |
| Enum | iota-based `type X int` |
| Relation 1:1 | `*Model` with `db:"-"` |
| Relation 1:N | `[]Model` with `db:"-"` |

## Example

### Input (Prisma schema via DMMF)

```prisma
enum Role {
  ADMIN
  USER
}

model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  name      String?
  role      Role
  createdAt DateTime @default(now()) @map("created_at")
  posts     Post[]

  @@map("users")
}

model Post {
  id       Int    @id @default(autoincrement())
  title    String
  authorId Int    @map("author_id")
  author   User   @relation(fields: [authorId], references: [id])
}
```

### Output

```go
// Code generated by prisma2go. DO NOT EDIT.
package models

import "time"

//go:generate enumer -type=Role -json -sql -text -trimprefix=Role
type Role int

const (
    RoleAdmin Role = iota
    RoleUser
)

// User represents the users table.
type User struct {
    Id        int32     `json:"id,omitempty" db:"id"` // primary key
    Email     string    `json:"email" db:"email"`
    Name      *string   `json:"name,omitempty" db:"name"`
    Role      Role      `json:"role" db:"role"`
    CreatedAt time.Time `json:"createdAt,omitempty" db:"created_at"`

    // Relations (not persisted, populate manually)
    Posts []Post `json:"-" db:"-"`
}

type Post struct {
    Id       int32  `json:"id,omitempty" db:"id"` // primary key
    Title    string `json:"title" db:"title"`
    AuthorId int32  `json:"authorId" db:"author_id"`

    // Relations
    Author *User `json:"-" db:"-"`
}
```

## CLI Flags

```
-i, --input     Input DMMF JSON file (or - for stdin)
-o, --output    Output Go file (or - for stdout)
-p, --package   Go package name
-c, --config    Config file path
--no-json-tags  Disable json struct tags
--no-db-tags    Disable db struct tags
--no-enumer     Skip automatic enumer invocation
```
